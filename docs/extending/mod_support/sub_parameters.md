# Subparameters

Multiple parameters for a given situation can be grouped together in a `SubParameter` class. These classes are similar to [datapack resources](datapack_resources.md), with the difference that sub parameters do not need to be provided separately from a datapack. Basically, this is just Rhombus' way of grouping nested fields from the JSON definitions.
